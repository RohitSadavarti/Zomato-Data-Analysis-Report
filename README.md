# Zomato-Data-Analysis-Report


📌 About

Exploratory data analysis of Zomato's Bengaluru restaurant dataset using Python — uncovering insights on ratings, online ordering trends, cuisine popularity, and location-wise restaurant performance.


📄 README Description

🍽️ Zomato Restaurant Data Analysis
A comprehensive exploratory data analysis (EDA) project on the Zomato Bengaluru dataset, built with Python. This project dives deep into restaurant trends across the city — analyzing how factors like online ordering, table booking, location, cuisine type, and cost influence customer ratings and engagement.
🔍 Key Insights

Restaurants with online ordering tend to have higher average ratings
Table booking availability strongly correlates with better customer satisfaction
BTM Layout, Koramangala & Indiranagar are the most restaurant-dense and highly voted locations
North Indian & South Indian cuisines dominate customer engagement by votes
Buffet and Café type restaurants consistently score higher ratings than delivery-only outlets

🛠️ Tech Stack
Python Pandas NumPy Matplotlib Seaborn Plotly
📊 Analyses Covered

Online order & table booking distribution across locations
Rating comparisons by order type, booking availability & restaurant type
Location-wise restaurant count, type breakdown & vote analysis
Top cuisines ranked by customer engagement

📁 Dataset
Zomato Bengaluru Restaurants dataset — available on Kaggle
